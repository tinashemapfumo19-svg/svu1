## Native State And Requirement

Native private/room message composer recall is implemented separately, including body/kind drafts, frozen retries, per-context bounds and caret restoration. Slash-prefixed message text remains literal. Current room administrative forms submit typed invitation/member/moderation/report/review operations with explicit targets, allowed choices, revisions, permissions and frozen pending keys. `CHAT_COMMAND_HISTORY.md` records verified room-definition recall. `ROOM_COMMAND_CONTEXT.md` now records connected member/moderation recall and native cross-form authority proof, including the failed fixture run and corrected full ten-case/unit/22-smoke run. Invitation/report/review recall is still not connected; additional native lifecycle/peer/async scenarios remain. These implemented forms must not be called complete administrative recall.

The remaining implementation must recall an explicit permitted administrative intent into current controls without silently executing it. It must preserve the unfinished draft, remain bounded and memory-only, and bind account/session, recipient, target and permission/membership lifetime. An unavailable or no-longer-permitted operation/target cannot be restored into another form, resource or account.

Deliberate submission of recalled intent must use freshly validated authority, current target revision, explicit confirmations/disclosure where required and a new request identity. It cannot copy an old URL, revision, grant, consent, key or authorization assertion into a new execution. Existing unresolved commands must retain frozen retry packets and lock recall until resolved/discarded; deliberate recall is not a retry. Restoring/clearing history alone must issue no server writes, read acknowledgements or consent changes.

Required proof includes valid/invalid targets, current operation sets, denied/revoked/regranted authority, changed membership/role lifetimes, account/route departure, busy/frozen commands, discarded/retried/new-intent distinction, unfinished field/selection restoration, independent resources, bounded history and desktop/mobile native workflows. Automatic replay, slash execution, credentials/configuration/diagnostic exposure, aliases and presence are not authorized by the source buffer. The broader native intent mapping remains open in the full goal.
