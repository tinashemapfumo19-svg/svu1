# Optional Chat Formatting

Implemented 2026-10-11; final verification completed 2026-10-12. All 594 unit tests, 20 native desktop/mobile browser cases and 22 smoke scripts pass on the unchanged guarded source. This stage does not close the complete legacy messaging audit.

## Contract

- User decision: preserve message words, no automatic word filter; account names without aliases or presence. Formatting is an explicit per-resource, in-memory display choice, initially off. Closing/revoking a context, changing identity or reloading drops it. No new local-storage preference is added.
- Private/room histories support B/I/U/S, seven restrained palette colors and explicit HTTP(S) BBCode links. The established parser supplies the AST; the native renderer supplies only whitelisted HTML. Arbitrary HTML, CSS, image embeds, credentialed/relative/non-HTTP links and nested anchors are rejected.
- Input is bounded to 4000 characters before parsing, with 1024 visited nodes, depth 12 and a 32000-character formatted-output ceiling. Source opening/closing slices and complete reconstructed text must match the original exactly. Any invalid, unsupported, over-limit or recovered tree falls back to the complete escaped original rather than partially rewriting it. A missing parser also falls back literal.
- Links escape their attributes and use `noopener noreferrer` and `no-referrer`. There is no automatic link detection, remote image fetch, automatic word replacement or archived JavaScript execution.
- Native stored bodies, request snapshots and room report evidence are not changed by presentation. Existing server boundary-whitespace trimming remains unchanged; this is not a new promise to retain formerly rejected or normalized payloads. Safety case bodies/reasons remain escaped literal regardless of history display preference.
- Composer commands explicitly insert markup into the selected draft, restore its selected text and emit the existing body-input event. Genuine edits can reset the private send key as before; display toggles do not. Over-length insertion is refused without truncating the draft. Busy, pending and detached controls cannot edit a draft.
- An unfinished link URL (maxlength 2000), its open control and the selected insertion point survive redraws within the same participant context. Link-entry state is not sent as an API field, written to persistent browser storage, mixed into room command drafts or restored after identity/context removal.
