## Native Contract

- A separate per-conversation/per-room Show smileys checkbox is default-off, independent of Show formatting. It survives local redraw, refresh and tab switching inside the same valid participant context, not reload, context disposal, revocation or identity change. Nothing new is stored in local/session storage.
- All supplied aliases are available, including case variants, quote/backslash tokens, overlapping arrows, weather and non-face symbols. Longest-first matching only processes raw text pieces; it never reprocesses generated HTML or matches inside generated attributes. Plain HTTP(S) chunks and formatted link labels remain textual. This conservative exclusion is not blanket legacy autolink/theme equivalence.
- Existing BBob parsing and exact original-slice reconstruction remain authoritative for optional formatting. Unsupported/unsafe/mismatched recovered formatted messages fall back entirely literal even when smileys are enabled. No arbitrary image BBCode/HTML or user-controlled source URL is accepted.
- Rendering allows at most 128 smiley images per message, within the existing 4000-character input, 1024-node, depth-12 and 32000-character formatted-output limits. Exceeding a bound produces the complete escaped literal body, not partial replacement or truncation. Original alias tokens are preserved in escaped image alt text.
- Picker buttons are ordinary non-submit commands with fixed hit areas, bitmap images, accessible names and alias tooltips. Each chooses the final alias from its mapping row, matching the supplied reverse-map overwrite approach. This does not prove configured historical ordering. Insertion replaces the selected draft text and leaves the caret after the inserted token, emits the existing genuine body-input event and restores focus. No synthetic storage/API command or auto-filter is introduced.
- Busy, frozen room-pending, disabled and detached controls cannot edit a draft. Length refusal does not truncate. Original stored bodies, frozen requests, read acknowledgements, participation and report/safety evidence are unchanged by either display toggle. Report bodies remain escaped literal, never image-expanded.
- Static access is closed to exactly the 19 named image files and one attribution notice. PNG/TXT MIME types and `nosniff` are supplied; arbitrary PNGs, catalogue/theme metadata, private files, scripts and archived paths remain denied. There are no remote image URLs or default notification/beacon calls.
